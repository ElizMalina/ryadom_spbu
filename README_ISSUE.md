# Issue #129 — Кризисный экран

Переиспользована отдельная автономная реализация `/crisis` с модулем `frontend/src/modules/crisis`, без импортов из психопросвета. Есть 112, mock-контакты, план безопасности, кнопка копирования сообщения, sidebar и адаптивная верстка.

```bash
cd frontend
npm install
npm run dev
```
Важно: кризисные телефоны и часы требуют проверки владельцем контента перед публикацией. Заглушки НЕ являются подтверждением актуальности. Маршрут `/crisis` доступен без авторизации.
