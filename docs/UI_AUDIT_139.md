# Issue #139 — Аудит UI главной страницы

Результат технической проверки исходного UI #61. Код главной включён в эту автономную QA-сборку, поскольку на `main` сейчас нет frontend.

## Автоматически

```bash
cd frontend
npm test
npm run build
```

Тесты проверяют семантику и наличие элементов **по исходному коду**, но не заменяют визуальный аудит.

## Ручная проверка (требует браузера)

- Desktop 1440 px: меню тёмно-фиолетовое, кнопка срочной помощи видна.
- Mobile 360 px: меню прокручивается, сетка становится одноколоночной, отсутствует горизонтальная прокрутка страницы.
- Tab: все ссылки и эмоциональные варианты доступны по клавиатуре; focus-visible заметен.
- Enter/Space: эмоциональные варианты управляются и не сохраняются после перезагрузки.
- Навигация: некоторые CTA пока ссылаются на будущие страницы — при интеграции их маршруты должны существовать.
- Контраст и WCAG 2.2 AA: требуется проверка инструментами браузера и ручная проверка экранным диктором.

**Статус:** автоматические smoke-проверки выполнены отдельно от дизайн-аудита; визуальный review и подтверждение соответствия макету не подменяются этим документом.
